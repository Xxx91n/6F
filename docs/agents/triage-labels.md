# Triage Labels

The engineering skills ask for five triage roles. This file maps each role to the label string this repo's tracker uses.

Where a decision or a term belongs is written once, in [`docs/authority.md`](../authority.md).

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When a skill names a role (for example, "apply the AFK-ready triage label"), use the matching label string from this table.

Edit the "Label in our tracker" column to match the labels this repo actually uses.
