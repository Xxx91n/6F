# Triage Labels

The engineering skills ask for five triage roles. This file maps each role to the label string this repo's tracker actually uses.

**[`docs/authority.md`](../authority.md) — the authority surface — is the one place that says where a decision or a term belongs.**

| Label in mattpocock/skills | Label in our tracker | Meaning                                      |
| -------------------------- | -------------------- | -------------------------------------------- |
| `needs-triage`             | `needs-triage`       | A maintainer needs to evaluate this issue    |
| `needs-info`               | `needs-info`         | Waiting on the reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent      |
| `ready-for-human`          | `ready-for-human`    | Needs a human to implement it                |
| `wontfix`                  | `wontfix`            | We will not act on this                      |

When a skill names a role (for example, "apply the AFK-ready triage label"), use the matching label string from this table.

Edit the "Label in our tracker" column to match the labels this repo actually uses.
