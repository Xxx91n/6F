# No MVP slice（spec-level 完整规划）
> 勘误补记（量测审计驱动 2026-09-15，#28 / A-033）：结构标签与 Date 字段补记；决策内容未改写。

## Context

决策理由：用户在 grill 中明确拒绝 MVP 框架（"先把一共这个仓库的本质就是要做哪些：全部都先规划好所有完整的内容"）；anysearch-cli "工程过度精良、产品定义未收敛" 的教训说明切片缺失会拖死产品定义；执行阶段的实现优先级排序属于本仓库外的工作，不在 grill/spec 范围。

## Decision

本仓库的产出是 spec-level 完整规划——5 scale 全部 spec 级同时落地，禁止"先做 X、Y/Z 之后再说"的 MVP 切片。
