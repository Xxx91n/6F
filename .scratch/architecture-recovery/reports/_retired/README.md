# _retired/ —— 退役守卫归档面（D-160② era-scoped 终态留档）

本目录收存 **已退役守卫的文件本体**——移出运行集后的考古面，非删除。

## 退役判据（D-160①）

唯一合法判据=**守护面本身消亡**：
- 守护对象移除；
- 被上层机制吸收；
- 被更强更窄契约取代（golden-master 退役出口先例）。

断言量/断言年龄/通过史**不作**退役判据（D-160⑥——ACH 277/571 实证＋LMAX「治理对象=失效件非体量」）。

## 处置流程

1. 面消亡提案经 **T3 审计窗逐件呈报裁定**（首件走链立先例）；
2. 守卫文件移入本目录（保原名）；
3. `known-red-manifest.json` retired 类增终态记录（id/guard/protected_surface/tier/retired_at/era/reason/decision_ref/archive_path 八要素）；
4. `guard-all-run.mjs` 运行集不再含该守卫；75a-M3 断言机检 schema＋归档实物存在＋原守卫出运行集。
