## 窗口边界纪律（D-101 精神沿用）

- 判据/charter/裁定临场不可改——变更须先走裁定链；探测面修语义必带预声明验证包（D-147 先例）。
- dry-run 无转窗条件禁长期化；过期差值禁直接转窗；S1 改写禁再自指。
- **工具链避雷**：bash 下 `2>nul` 会写真 `nul` 文件；ctx 沙箱 bash 注入 NODE_OPTIONS 污染 stderr——宿主级测试先 `env -u NODE_OPTIONS`；写文件经 node/ctx 时 `\u0000` 字面量会物化为真 NUL（A-096 教训）。
- 报告命名纪律：`{date}-r{NN}-exec-report.md`／`-audit-report.md`；DB 探查=副本探查原件 sha256 前后校验。
- **退役判据=面消亡唯一合法路径**——禁命中率/年龄/通过史/断言量作判据（D-160 负向）；退役经 T3 窗逐件非批量；**retired 发射腿禁预建**（D-164-b）。
- **skip 三态语义**：skip=环境缺席、xfail=该工作但物不在——禁混标；skip 不进 allOk 禁折 pass；**组级 SKIP 同纪律组粒度沿用**（D-164-a③）；**组粒度=探测粒度终态上限**（D-167-a——断言级 need() 无真实实例禁建制；GREEN 行级+组跳标位+allOk 收紧三重披露足够，禁 GREEN-WITH-SKIP 方言态值污染机读面）。
- **哨兵触发钉事件非纯时间窗**（D-164-b／D-169-a②——消亡判据/误声明/npm v12/批2-β 三事件锚；未注册触发器不算锚定——注册动作随收口节兑现）。
- **git-object 访问零写入**——禁主仓 fetch/unbundle 写 object store（D-074）；自足件首选临时仓+alternates 借用。
- **执行窗必带时点锚＋欠账三要素**（D-165④＋D-170③）——具名 owner＋时点锚＋复验方式缺一不算锚定；无限期执行窗=变相 accepted-risk 绕五要件禁制。
- **Stage-1 逐案 charter**；**Stage-2 四判据+30 日窗未达标禁启动**（判据②已 PASS——余①③④值守；Macro-A 绑 DoR-b 未满足禁因外部压力开工）。
- **冗余断言处置判据**（D-167-c，Bond 判据）：「这个断言还能失败吗」——闸后同语句重言必不能败→删（谓词改而断言不随=假绿风险）；覆盖闸未覆盖后果者留；不建常设普查机件。
