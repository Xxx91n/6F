- **skip 三态语义**：skip=环境缺席、xfail=该工作但物不在；组粒度=探测粒度终态上限（D-167-a）。
- **哨兵触发钉事件非纯时间窗**（D-164-b／D-169-a②）；未注册触发器不算锚定；判据读数须有机读锚。
- **git-object 访问零写入**（D-074）；自足件首选临时仓+alternates。
- **执行窗必带时点锚＋欠账三要素**（D-165④＋D-170③）。
- **Stage-1 逐案 charter**；**Stage-2 四判据+静默窗未达标禁启动**。
- **冗余断言处置判据**（D-167-c，Bond 判据）：「这个断言还能失败吗」——闸后同语句重言必不能败→删。
- **RA 五要件＋到期二分**（D-169-b②/D-171）：判据引用＋不修理由＋可验证补偿控制＋具名裁者＋到期日+复审钩——缺一=静默丢弃禁为；**守卫自身缺陷的 AR=自我指涉悖论不成立**（D-183④）。
- **开工对表边界**（D-185）：核实义务=guideline 式非硬 gate（失真即阻断开工等书更新=驳回形态）；差异行走既有登记面禁新建通道；只钉声称态条目不外溢。
- **迁入闸边界**（D-184）：探测件未落盘=迁入冻结期；歧义处置全偏按除号=安全向立法钉死；修复禁动 8 消费位断言语义；残差入 known-errors 册诚实声明禁假装清零；禁借修复重批 golden/钉值。
- **降级形态边界**（D-186）：degraded≠incident（禁异常登记稀释真信号）；组成标注必填非可省；复审钩=连续 3 轮 100% 具体计数非「以后再议」；独证腿可选非义务。
- **换代盘点边界**（D-187）：保护区节只增不删；节外钉须清单显式登记；盘点步非新 check 文件（自指 fragile）；75a 不适配则负向列暂人工（禁另写解析器）。
- **Frozen 证据包**（D-172②＋D-182）：历史证据类工件禁扫 regen 批；重钉=git 原 blob 字节级恢复；代表性衰减=声明面处置非工件处置。
- **跨仓主权**（D-172④/D-182）：sibling 仓不立案代排产；漂移移交=观察项非代管；不对上游发外联。
- **勘误链纪律**（D-146⑤/D-165/D-181）：链式追加不改写原条目；声明件扩面=勘误节追加。
- **等待期立法边界**（D-175⑧）：预备件禁绕三问筛；禁内部/模拟仓证据充 DoR-b。
- **自动分诊边界**（D-179④）：自动 discard 产物=显式驳回形态——守卫产出处置必留 D-140② 记账面。
- **漏报向守卫缺陷=被支配缓挂禁型**（D-183④）：探测面缺陷分 latent/active；latent 缓挂合法但五要件成本须真实支付。

## 用户闸门（勿越）

- push/merge：逐次授权；栈上未 push 分支按 but status 实态管理。
- 宿主侧操作（插件安装/会话执行/IDE 试用驱动）=用户驱动面；宿主缺陷不代报官方渠道。
- social-card.png 上传=所有者 web-UI 手动操作。
- B 轨官方目录提交不授权不触碰（D-042 收窄义在案）。
- 外部评审工件入仓须先走摄入分诊四档（D-142/D-146）——证伪驳回须附核实依据。
- 审计 finding 处置态封闭三档（D-169）；**RA 档案起草权在 Agent、批准权在用户**。
- 规程生效时点=自落盘 commit 起对新行为生效、落盘 commit 自身豁免（D-148③）。
- 试用关窗≠缺陷清零（D-151②/D-152⑤）。
- Stage-1 宿主邀请对象=用户主权逐案闸门（D-162⑤）；Stage-2 公开推广=判据包达标后用户拍板启动（D-162③）；**(c) 面候选件=呈用户裁量位，执行批只起草不拍板**（D-175⑦）。
- 「定稿」语义=分层（D-165/D-170）——裁定层闭环声明与验收层未达事实双行呈报，禁单句「已完成」。
- **workflow_dispatch 实跑=外触副作用面**（D-176 scoping——须用户单独授权非默认复验件）。
- **atomcode 进程处置=用户主权**——调研进程在途未归禁我杀；**降级形态合法化**（D-186——后台未归/fallback 按 degraded_performance 登记非异常；配额耗尽=唯一不续跑例外；续跑锚定限非配额类中断）。
