## 4. Lessons 候选

- **but hunk id 陷阱**：but diff 行首 `qu:8` 型 ID=hunk 级（单波次），but status 裸字母=file 级（全量）——单文件多 hunk 场景传 file id 或枚举全 hunk；部分提交后用 amend 归位（本批实证 amend 后 change-id 链稳定）。
- **amend 后指针随行**：amend 重写 SHA——同窗文书引用实现腿 SHA 时须在 amend 定稿后回填（旧 SHA 不可达=非法指针，指针纪律对自体文书同样生效）。
- **git subject 含管符**：subject 原文含 `|` 时 GFM 表格内必须截断（校验位仍可辨）或移出表格——截断属位形修缮非命题变更（D-181 轻档语义）。
- **反向闸负载判据的假阳性形态**：纯数字 run ID／跨仓 SHA 与 git SHA 同位形——恒 WARN 面即 D-197④ 候选清单的实义（不扩判 FAIL，不预设豁免）。
