# R51-Q2 调研题面 —— 「指针字段」适用范围划界（commit 引用管制面的宽窄裁定）

（提交 atomcode-research 深调研；账本=唯一事实源立场，调研须回顾 decision-ledger 全部 current 记录、docs/adr、CONTEXT.md 词条、工业界成熟落地心智模型为重点。）

## 背景

本仓=五尺度工程内容审计产品的 spec-level 规划+治理仓。承接 D-188（本轮已采，commit 指针实名化纪律）：文书面「变更 commit 指针」类字段法定形=git SHA ≥12 hex＋("subject") 校验位；合法性判据=写入时点 cat-file -e 存在 ∧ 整合线祖先集可达；GitButler 短码（wmu/xqr 类 per-session UI 便利码）禁当指针字段、仅叙述段可作别名。

悬而未裁=**划界**：「哪些位置算指针字段（入规受检）、哪些算叙述段（提及自由）」。实证面：R51 审计 F1=勘误节指针列写模糊语/短码；W8=§7 补钉写 orphan 孪生 hash；W6=账本 T3 读数表 `(wmu)` 括注型残留——三处形态各异（表格指针列／补钉表值／叙述段内括注）。本仓文书生态：decision-ledger（D 账行＋轮次收口节＋T3 读数表）、handoffs/next-round.md（任务书）、reports/*.md（审计报告＋调研存档＋预声明包）、docs/adr、WORKFLOW.md 条文、AGENTS.md 操作行。

约束面：D-148③ 不溯既往；机检面与人工面分工（D-188④ 主线可达性留人工）；管制须避免过度税（每个叙述提及都背核验义务=劣化）；划界判据本身须可机检或可人工判别无歧义。

## 候选

(i) **窄口径（列级）**：只管制已命名的指针列/字段位——勘误节「变更 commit 指针」列、登记表证据锚列等明示字段标题位。利=边界最清机检最易；弊=W6 类叙述段括注漏管，同型缺口永续。
(ii) **中口径（职能级）**：按语义职能判——「该位置的职能是唯一定位一个 commit」即入规（勘误指针列／去向表指针位／兑现登记证据锚／审计固定点与返工链／T3 表 commit 指代位／账行括注当其为唯一指代手段时）；叙述流中顺带提及不入规。判据=职能判非字面形态判。利=覆盖 W6 同型缺口＋散文不背税；弊=职能判别有人工裁量成分，机检需字面化近似（如表格列头白名单＋括注位模式）。
(iii) **宽口径（全文面）**：文书面一切形如 SHA/短码的串入规。利=机检最简零裁量；弊=过度管制税——叙事提及全部背核验义务，写账本负担陡增，且 SHA 形字串误报面大（文档示例、截断引用）。
(iv) **分层口径**：结构位（表格列/登记字段）从严法定形＋叙述段从宽只禁「裸短码单独承担定位」（即叙述段内 SHA 不限位数但短码必须伴 SHA 同现或禁现）。利=分级按风险；弊=规则多一条裁量缝。

## 调研要求

1. 工业界成熟心智模型（重点）：规范化文档中「引用位 vs 提及位」分层管制的先例——如 Conventional Commits/git trailer 的 footer 机读位 vs body 叙述位二分；kernel Fixes tag（仅 footer 位受检）；Gerrit/Differential 的 field vs comment 分层；IETF/RFC errata 的字段引用惯例；schema 化文档（YAML front matter/结构化字段）与自由散文的职责分工；lint 生态「结构性字段严检＋散文不检」的先例（gitlint 只检 subject/body 结构位不检语义）；审计/合规文书（POA&M、FDA 483 response）中引用纪律的分层实践；「按位置分档管制」vs「按内容形态管制」的治理先例优劣。
2. 判候选：四候选各评强弱——特别裁决：①职能级判据（ii）在工程文书的可机械化程度（表格列头白名单+括注位正则是否足以承载，业界有无类似近似判据先例）；②叙述段括注型指代（如「（wmu）」「（c6cb5a33）」）应否入规——它们在被引用时是否事实承担指针职能；③宽口径的过度税在文档量大的治理仓中的实证先例；④划界判据的可判性——「职能判」在审计窗人工复核中的可操作性。
3. 冲突扫描：结论是否与本仓 current 决策冲突（重点 D-188 指针实名化、D-181 勘误三字段、D-146⑤ 链式追加、D-161④ footer 机读位 vs subject 人读位分工、D-165/D-170 分层定稿、D-149 守卫入列规程、D-185 开工对表、D-095 枚举 closed 面、D-148③ 不溯既往）。
4. 推荐+理由+置信度；缺口如实标位。
